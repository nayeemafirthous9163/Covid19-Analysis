# Covid19-Analysis
An interactive Power BI dashboard that uses dynamic reporting to examine case trends, death rates, and recovery statistics by cleaning, transforming, and visualizing worldwide COVID-19 records.

OVERVIEW OF THE PROJECT

This Power BI project produces a thorough two-page interactive dashboard designed to examine COVID-19 pandemic patterns both globally and nationally. It analyzes past health data to provide both localized in-depth analyzes of cases, death, and recovery distributions as well as high-level worldwide visibility.

Page 1: Global Overview - Offers macro-level epidemic movement across time, cross-country measures, and high-level international tracking.
Page 2: India Deep-Dive - A targeted analytical perspective that isolates state/regional distributions, recovery vs. mortality dynamic metrics, and localized metrics within India.

KEY FEATURES

Dedicated dashboards for Global and India analysis are part of the multi-page analytical structure.
1. Global & Regional Tracking: View and filter COVID-19 metrics over configurable times, countries, and regions.
2. Trend & Time-Series Analysis: A graphic depiction of mortality, recovery rates, confirmed cases, and active cases over time.
3. KPI Metrics & Gauges: Target gauge charts with summary statistics (Total Cases, Active Cases, Deaths Daily, Recovery Daily) and dynamic single-card visual metrics. Map graphics, dynamic bar charts, and continuous time-series graphs with cross-filtering options are examples of interactive visualizations

TECH STACK & TOOLS USED

1. Data Cleaning & Preprocessing: Python (Pandas, NumPy)
2. Business Intelligence: Microsoft Power BI Desktop
3. Data Transformation & ETL: Power Query (ETL pipeline, unpivoting, type casting)
4. Data Modeling & Calculations: DAX (Data Analysis Expressions) for custom measures and calculated columns
5. Data Format: Tabular Data Model schema

HOW TO RUN/OPEN TEH PROJECT

1. Prerequisites: Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/) on your Windows machine.
2. Download: Download the project file (`.pbix`) or extract the repository archive.
3. Open: Double-click the `.pbix` file to open it directly in Power BI Desktop.
4. Interact: Click on slicers, dynamic visual elements, and tab pages to explore the global and India reports.
